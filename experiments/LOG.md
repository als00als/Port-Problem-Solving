결론: 한글 행에는 정답이 후보에 포함되는 비율보다 최종 정확도가 크게 낮다. 현재 가장 중요한 개선 대상은 한글명과 카탈로그 영문명 간 연결 및 한글 후보 재랭킹이다.

다음 실험 가설

1. 한글/영문 선박명 연결 규칙 추가 -> 한글 후보 포함률 개선 기대

3. 후보 생성 변경과 재랭킹 변경은 별도 실험으로 비교

다만 하나의 그룹 분할 결과이므로 독립적인 그룹 분할에서 추가 검증한다.

채택 여부:
일반화 후보 모델로 잠정 채택

## EXP-013: fuzzy confidence 기반 적응형 후보 검색

검증 설정:
- `target_vessel_id` 기준 그룹 분할 사용
- seed 42와 seed 123 독립 그룹 분할에서 각각 평가
- EXP-008과 동일한 fuzzy 점수 기반 규칙 재랭커 사용
- 기본 fuzzy limit/cutoff/max: 10/60/30
- 확장 fuzzy limit/cutoff/max: 20/55/40
- 학습·검증 정답을 임계값 결정에 사용하지 않음

변경점:
- 한글 행의 fuzzy top-1 점수와 top-2 점수 차이를 계산
- `top1_score < 0.70`이고 `margin < 0.02`인 행만 확장 검색
- 확장 대상은 fuzzy 후보 수와 cutoff를 완화
- 후보 생성 외의 재랭킹 방식은 EXP-008과 동일하게 유지

결과:
- seed 42 확장 행 수: 54
- seed 42 한글 정확도: 0.6584
- seed 42 가중 점수: 0.6820
- seed 42 한글 후보 포함률: 0.8889
- seed 42 실행 시간: 8.964초
- seed 123 확장 행 수: 59
- seed 123 한글 정확도: 0.6284
- seed 123 가중 점수: 0.6630
- seed 123 한글 후보 포함률: 0.8391
- seed 123 실행 시간: 9.450초

기준 모델 대비:
- seed 42 가중 점수: EXP-008 0.6360 → 0.6820
- seed 42 한글 후보 포함률: 0.8560 → 0.8889
- seed 123 가중 점수: EXP-009 0.6470 → 0.6630
- seed 123 한글 후보 포함률: 0.8314 → 0.8391
- 후보 확장 대상은 각 검증셋의 54행과 59행으로 제한

결론:
fuzzy confidence가 낮고 1·2위 후보의 점수 차이가 작은 행에만 검색 폭을 확대하자 두 독립 그룹 분할에서 한글 정확도와 가중 점수가 모두 개선되었다.
확장 대상 행 수는 적었지만 후보 포함률과 최종 정확도가 함께 상승했으며, 실행 시간 증가도 제한적이었다.
현재 최종 후보 파이프라인은 적응형 fuzzy 후보 생성과 fuzzy 점수 기반 규칙 재랭커의 조합으로 정한다.

채택 여부:
최종 후보 파이프라인으로 잠정 채택

제출 결과:
- 제출 파일: `submissions/final_exp013_adaptive.zip`
- 리더보드 점수: 0.65766
- seed 42 로컬 가중 점수: 0.6820
- seed 123 로컬 가중 점수: 0.6630
- seed 123 로컬 대비 차이: -0.00534

해석:
리더보드 점수는 seed 123 독립 그룹 분할 점수에 더 가까웠다.
따라서 seed 42 row 또는 group 분할의 낙관적인 성능보다 독립 그룹 분할 결과가 실제 테스트 일반화 성능을 더 잘 반영한 것으로 판단한다.
